# TOEFL Claude 101

Paket belajar bahasa Inggris untuk persiapan TOEFL bersama Claude.

## Struktur folder

```
toefl-claude-101/
├── README.md
├── 00-roadmap/            Roadmap Basic → Advanced → TOEFL Prep
├── 01-skill/              SKILL.md untuk membuat materi kursus
├── 02-prompts/            Template prompt memulai chat Claude
├── 03-materials/          Hasil materi kursus (isi bertahap)
│   ├── 01-basic/
│   ├── 02-intermediate/
│   ├── 03-advanced/
│   └── 04-toefl-prep/
└── 04-progress/           Catatan kemajuan dan error log
```

## Cara pakai

1. Baca roadmap di `00-roadmap/`.
2. Mulai chat Claude dengan template di `02-prompts/`.
3. Lampirkan `01-skill/SKILL.md` saat meminta materi, lalu simpan hasilnya (`.md`) ke folder level yang sesuai di `03-materials/`.
4. Catat kemajuan dan kesalahanmu di `04-progress/`.

Catatan: file `.gitkeep` hanya penanda agar folder kosong tetap ikut tersimpan di Git. Hapus bila folder sudah berisi file.
